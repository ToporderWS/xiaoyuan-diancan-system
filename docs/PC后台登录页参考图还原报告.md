## 3. 主视觉素材来源 / 生成方式

- **来源**：AI 图片生成（文生图），提示词方向 = "日系生活/商业插画质感的校园食堂场景 + 明亮自然光 + 暖色 + 前景年轻女学生边吃边看手机 + 档口红雨棚与菜单灯箱 + 3~5 名学生 + 强空间纵深"，并显式禁止：任何文字/字母/数字/标识/水印、科技感、赛博霓虹、3D 塑料质感、扁平矢量色块、人物过多。
- **只生成"场景插画本身"**：`校园点餐管理系统`、英文副标题、slogan、菜品管理/订单管理/数据统计/系统设置 **全部仍由 HTML/CSS + 内联 SVG 渲染**，没有烧进图片，避免乱码并保证任何分辨率下都是矢量级清晰。
- **后处理（纯像素，不动文件名以外的任何东西）**：
  1. 去掉生成模型自带的右下角水印（不到 140×76 px 的区域，用正上方同宽内容纵向延拓 + 羽化过渡填补，不做镜像以免出现重复形状）；
  2. 画面顶部菜单灯箱行做"由强到弱"的景深虚化（band 190 px），消掉不可读的伪文字、同时保留菜品照片轮廓，读起来像浅景深；
  3. 导出 `login-hero.jpg`（quality 90，progressive）。
- **落地方式**：`admin-pc/public/login/login-hero.jpg`，用 `<img>` + `object-fit: cover` + `object-position: 50% 100%` 渲染。**全站无任何远程 URL**，不依赖外链。
- **选片**：同轮生成了 2 张候选（另一张人物偏右、与右栏接缝冲突）已弃用，源图与弃用图保留在临时目录备查，未留在 `public/`（`public/login/` 现在只有 `login-hero.jpg` 一个文件，`dist/login/` 同样）。

## 8. 是否存在横向 / 纵向溢出

**均不存在。** 实测三档：

| 分辨率 | `scrollWidth` vs `innerWidth` | `scrollHeight` vs `innerHeight` | 横向滚动条 | 纵向滚动条 |
|---|---|---|---|---|
| 1920×1080 | 1920 vs 1920 | 1080 vs 1080 | 无 | 无 |
| 1600×900 | 1600 vs 1600 | 900 vs 900 | 无 | 无 |
| 1366×768 | 1366 vs 1366 | 768 vs 768 | 无 | 无 |

实现手段：`.login { height: 100vh; overflow: hidden }` + 左侧三段式 flex（品牌区 `flex: 0 0 auto`、场景图 `flex: 1 1 auto; min-height: 120px`）+ 全量 `clamp(min, vw/vh, max)` 尺寸，高度不足时优先压缩场景图而不是撑出滚动条；卡片内部所有纵向间距用 `vh` 夹取，768 高度下仍能完整放下（610 < 768）。
