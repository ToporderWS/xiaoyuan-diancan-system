## 二、设计决策（本轮定下的规则）

### 2.1 色彩：把品牌红从「铺色」降为「语义强调色」

旧版小程序大量使用红色渐变大面积铺底（`.page` 背景 `#FFF5F5`、头部大红渐变、Tab 红底胶囊、我的页大红 hero 块）。本轮改为：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--co-primary` | `#e53935` | 主按钮、选中态、价格、状态圆点 |
| `--co-text` / `--co-text-2` / `--co-text-3` | `#1f1d1b` / `#6e6864` / `#a29b96` | 三级文字 |
| `--co-bg` / `--co-card` | `#f7f6f4` / `#ffffff` | 页面底色 / 卡片 |
| `--co-line` | `#f0eeec` | 分隔线 |
| `--co-success` / `--co-warning` | `#3f9159` / `#d98324` | 语义色 |

**禁止事项落地**：页面底色统一 `#f7f6f4`（暖灰白），不再出现 `#FFF5F5` 粉色铺底；红色渐变块全部移除；头部、Tab、个人资料卡一律改白底。

### 2.2 统一公共类（写进 `App.vue` 全局样式，各页只复用、不自造）

`.co-page` `.co-card` `.co-card--flush` `.co-card__title` `.co-card__sub` `.co-section` `.co-btn`(`--ghost/--plain/--disabled/--sm`) `.co-price` `.co-tag`(`--gray`) `.co-row` `.co-ico`(`--sm`) `.co-empty-wrap` `.co-empty`(`__art/__title/__desc/__btn`) `.co-loading` `.co-loadmore` `.co-bar` `.co-stepper` `.co-check` `.co-mask` `.co-sheet` `.co-field` `.co-ph` `.co-safe-bottom` `.co-tap`

### 2.3 Empty State 统一结构

固定四段式：**插画 → 标题 → 说明 → 主按钮**，整体在内容区（`min-height: 66vh`）水平居中。各业务只换插画与文案，布局规则不再各写一份。空购物车与空订单从原先「文字贴顶 + 按钮浮在半空」改为居中重做。

### 2.4 图标体系

彻底移除 Emoji（旧版曾用 🛒🧾🖼️📝🔒☎️ℹ️📱 等）。改由程序化生成的 PNG 图标集统一提供，风格为**线性 + 圆角端点 + 24 单位网格**，含灰 / 白 / 红三套配色。

### 2.5 安全区

所有贴底元素统一使用
`padding-bottom: calc(16rpx + constant(safe-area-inset-bottom));` + `env()` 双写，
覆盖购物车结算栏、确认订单提交栏、订单详情操作栏、底部弹层。

## 三、A 部分：PC 管理后台登录页

### 3.1 布局

- 左右分栏：左 `60%`（`flex: 0 0 60%`）+ 右 `40%`，`min-height: 100vh`。
- 左侧自上而下：品牌头（厨师帽图形 + 中英标题）→ slogan → 四项能力展示（菜品管理 / 订单管理 / 数据统计 / 系统设置）→ 场景插画（`flex: 1` 占满剩余高度）。
- 右侧：白色登录卡片，垂直水平居中，`max-width: 400px`。

### 3.2 品牌图形（替换旧「碗 + 两点笑脸」）

- 新增 `admin-pc/public/brand-logo.svg`：圆角红底 + 白色厨师帽（三朵圆 + 帽箍）。
- 重写 `admin-pc/public/favicon.svg` 为同一图形，覆盖旧图标。
- 左侧布局栏顶部的 logo 同步改为 `/brand-logo.svg`（`admin-pc/src/layout/index.vue`）。

### 3.3 左侧场景插画（`admin-pc/src/components/LoginScene.vue`）

- **纯手绘 SVG**（`viewBox="0 0 760 500"` + `preserveAspectRatio="xMidYMid slice"`），非位图、非 AI 生成图、无任何远程 URL。
- 画面元素：窗（暖阳 + 远景楼群窗格 + 树丛 + 窗台盆栽）、两盏吊灯、**今日推荐展示板（内嵌 4 张项目本地真实菜品缩略图 `/dishes/dish-1..4.jpg`）**、档口雨棚（品牌红 + 品牌语 + 扇贝边）、打饭柜台（四个餐盘 + 蒸笼）、两位学生背影、左右绿植。
- **安全区设计**：窗口 / 展示板 / 吊灯 / 前景人物全部收在 `x 84~676` 安全区内，任何分辨率都不会把主体裁掉；雨棚、柜台、绿植为可出血元素。
- 红色只出现在雨棚条带 + 灯头小色块，占全屏面积约 2%，满足「禁止大面积红」。

### 3.4 分辨率适配（实测）

| 分辨率 | 视口 | 内容高度 | 纵向溢出 | 横向滚动 | 登录卡片 |
| --- | --- | --- | --- | --- | --- |
| 1920×1080 | 1920×1080 | 1080px | 无 | 无 | 完整可见 |
| 1600×900 | 1600×900 | 900px | 无 | 无 | 完整可见 |
| 1366×768 | 1366×768 | 768px | 无 | 无 | 完整可见 |

额外的降级断点：`≤1280px` 左栏收窄至 54% 且能力项转 2 列；`≤1024px` 转上下布局并收起插画；`≤560px` 隐藏能力项。

### 3.5 登录功能（未改动，保留真实能力）

保留原有 `el-form` 校验、`adminStore.login` + `fetchInfo`、`redirect` 回跳、`记住账号`（只存账号不存密码）、`忘记密码` 弹窗（ElMessageBox 提示）。仅调整视觉样式（输入框 44px 高、圆角 10px、聚焦态红描边）。
